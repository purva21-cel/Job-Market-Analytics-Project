# Job Market Analytics and Salary Prediction

A Streamlit web app for exploring online job listings and predicting salary in LPA using regression models.

## Files needed in the GitHub repository
- `app.py`
- `requirements.txt`
- `online_job_listings_salary_dataset.csv` (your dataset)
- `B1_B1_11_SI_PROJECT_Purva_.ipynb` (optional, your original Colab notebook)

## Deploy
1. Upload all required files to a GitHub repository.
2. Open https://share.streamlit.io/ and sign in with GitHub.
3. Click **Create app** / **Deploy an app**.
4. Select the repository and branch (usually `main`).
5. Set the main file path to `app.py`.
6. Click **Deploy**.

The app trains regression models from the CSV and chooses the model with the lowest RMSE. Do not upload passwords, API keys, or private information.
